# Statement of Work (SOW): PulseFit iOS MVP

**Project Title:** PulseFit Personal Workout & Nutrition Tracker  
**Client:** PulseFit Labs Inc.  
**Contractor:** Mobile Engineer (Freelance)  
**Contract Type:** Fixed-Price Milestone ($3,200.00 Base)  
**Hourly Rate:** $85.00 / hour (Agreed Change-Order Rate)  
**Milestone Timeline:** 4 Weeks (40 Hours)  

---

## 1. Project Overview & Scope Baseline
This agreement covers the development of the standalone iOS MVP using Swift and SwiftUI. Local storage operates via SwiftData / CoreData. Cloud syncing and third-party hardware peripherals are explicitly deferred.

---

## 2. Included Deliverables (In-Scope)
1. **Local Workout Logging:**
   - Pre-loaded database of 120 standard exercises.
   - Reps, sets, and weight tracker with historical graphs.
2. **Local Timer & Stopwatch:**
   - Rest timer between sets with local audio chime.
3. **Daily Nutrition & Water Logger:**
   - Manual calorie and macronutrient (protein, carbs, fat) entry.
4. **Offline Local Persistence:**
   - SwiftData offline-first database with iCloud backup fallback.

---

## 3. Explicit Exclusions (Out-of-Scope / Phase 2)
1. **Apple Watch / Wearable Sync:**
   - watchOS companion app and real-time heart rate sensor streaming.
2. **Video Streaming & Exercise Demos:**
   - In-app video playback player and CDN video hosting integration.
3. **Social Leaderboard & Friend Activity Feed:**
   - User social profiles, friend requests, and workout feed comments.
4. **Barcode Food Scanner:**
   - Camera OCR / OpenFoodFacts barcode scanning API integration.
5. **AI Meal Plan Recommendation Engine:**
   - Personalized generative meal planning algorithms.
